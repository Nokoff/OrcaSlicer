# Changelog

## 2.4.1 - 2026-09-25

### Fixed

- Cutting a model now retains painted filament colours, including partial brush-painted facets, mirrored or transformed models, repeated cuts, contour cuts, and tongue-and-groove cuts.
- Newly exposed cut faces no longer inherit paint from nearby model surfaces.
- Contour and groove cuts now retain each model part's filament, material, and volume settings.
